# Resources

Start with your block's **selected-part datasheet**, then its manufacturer's reference schematic. Record the actual selected parts in [Components](Components.md).

| Work | Starting resource | Use it for |
| --- | --- | --- |
| Schematic basics | [KiCad schematic guide](https://docs.kicad.org/10.0/en/eeschema/eeschema.html) | Sheets, wiring, footprints and ERC |
| STM32 | [ST documentation](https://www.st.com/en/microcontrollers-microprocessors/stm32-32-bit-arm-cortex-mcus/documentation.html) | Exact MCU datasheet and family hardware guide |
| Power | [TI buck resources](https://www.ti.com/product-category/power-management/buck-step-down.html) | Regulator examples; verify topology against battery range |
| Sensors | [ST sensor documentation](https://www.st.com/en/mems-and-sensors/documentation.html) | Example sensor application notes |
| Radio | [Semtech RF resources](https://www.semtech.com/products/wireless-rf) | Example radio/reference designs |
| Storage | [SD Association specifications](https://www.sdcard.org/downloads/pls/) | Card interface background |
| GPS | Selected module integration manual: TBD | Antenna, power and UART requirements |
| Pyro channels | Club recovery reviewer + selected component manuals: TBD | Approved circuit/interface review |
| Indicators | Selected LED/sounder datasheets: TBD | Current, drivers and control requirements |

Manufacturer examples are not component selections. If a member is stuck, ask the reviewer for one relevant reference rather than adding a large reading list.
