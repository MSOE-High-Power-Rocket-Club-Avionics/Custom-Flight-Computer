# Board Integration

**Issue:** TBD

## Function

Connect the block schematics into the three-board stack and agree on shared connectors, power requirements and mechanical interfaces.

## Inputs

| Connection | From | Details |
| --- | --- | --- |
| Block interfaces and power needs | Block owners | Signals, electrical limits and load requirements |
| Board dimensions and mounting | Mechanical team | Outline, holes, stack spacing and clearances |
| MCU pin allocation | MCU owner | Agreed peripheral and GPIO assignments |

## Outputs

| Connection | To | Details |
| --- | --- | --- |
| Board connector table | All block owners | Contact numbers, net names, ratings and orientation |
| Connected board schematics | Review/layout team | Reviewed connections between blocks |
| Combined power requirements | Power owner | Continuous and peak loads for each rail |
